QtGMS - Windows XP x86

Extract the complete archive to a writable folder and run QtGMS.exe.
Keep the DLL files and subfolders beside the executable. Do not run the
executable directly from inside the ZIP archive.

Included files:
  QtGMS.exe          Editor and game compiler; interface translations embedded
  *.dll              Qt and MinGW runtime libraries
  platforms/         Windows platform plugin
  imageformats/      Image format plugins
  iconengines/       Icon rendering plugins
  printsupport/      Printing plugin
  lib/               Built-in action libraries
  runtime/windows/   Game Runner and DirectX runtime dependencies
  licenses/          Third-party licenses and notices
  qt.conf            Relative Qt plugin paths

A Qt SDK, compiler toolchain, FFmpeg, or original editor installation is not
needed to use this package. Language and recent-project settings are stored
in the current user's Windows settings. Game builds go to the project's
build folder.
